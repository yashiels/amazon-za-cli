# Changelog

## 0.1.0

- Read-only product search, inspection, comparison and query suggestions for amazon.co.za.
- Local price watches with fixed baselines, lowest seen prices and optional ZAR targets.
- Stable JSON output, structured inclusion warnings, bounded GET requests and WAF detection.
- Anonymous session caching and a signing diagnostic command.

JSON compatibility: fields may be added within a 0.x minor version. Field removals require a minor version bump and a changelog entry.
